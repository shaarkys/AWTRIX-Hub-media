# NetatmoV2 implementation contract

Target: TC002 / AWTRIX NG, 52x16. New standalone app NetatmoV2. Original attachment by Oliver Rummeyer is a behavior reference; implement new code and original procedural artwork. No copied icons, icon settings, raw credentials, tokens, personal API responses or station IDs in repository/test fixtures. Public GitHub update is authorized; physical install and live station calls are not necessary for offline implementation.

## Diagnosis and transport

Original matches exact configured German room names, uses whitespace/order-sensitive substring regex parsing, requires Temperature for every module (drops rain/wind), and has no useful signed-in empty-state page. Use real json.load on bounded getstationsdata response. TC002 native OAuth only: metadata authorize=https://api.netatmo.com/oauth2/authorize token=https://api.netatmo.com/oauth2/token api=api.netatmo.com scope="read_station" auth=body. import oauth; ready/get with callback(body,status), opts cap65536. No credential configuration or manual token endpoint code. Client ID+secret alone cannot authorize account data; user signs in in clock settings. Calls refresh/poll in loop/setup only. APIs verified official AWTRIX docs guides/oauth/, guides/scripting/network/, guides/scripting/several-apps/ and Netatmo dev.netatmo.com/apidocumentation/weather (dynamic browser docs).

Cloud getstationsdata updates about10min per official docs. Default poll10min, minimum5. Do not switch to near-realtime homestatus; V1 cloud data is intentional. Never treat unchanged reading as a stale fault; age uses dashboard time_utc in seconds, not value equality and not HTTP fetch time when source timestamp exists. Use received monotonic timestamp only if no valid source timestamp or clock epoch unknown. Stale after45min default, expired after180min default. Stale means amber indicator plus last good values; expired means module NO DATA, never fresh-looking old values. Missing/unreachable module can keep last good readings with stale indicator until expiry. No daily persistent writes. No charts/history requests needed; use daily min/max present in dashboard data.

## Stable data/render interface

netatmo_graphics.be.inc defines class NetatmoArtwork with paint_page(page, elapsed_ms, index, total, health) and paint_status(code, elapsed_ms). Called only by core draw. Status codes signin/loading/no_modules/disabled/network/auth/parse; any unknown -> generic DATA WAIT. health fresh/stale/expired. All artwork only local draw calls, no store/OAuth/rotation/time; clock elapsed supplied, original4sec deterministic loop. Use clear/font("small")/text/pixel/line/rect_fill, min/max/clamp globals as existing apps; native math.sin/math.cos for the turbine; no external libraries. Native font metric text_ink_width if used must be mocked accurately. ASCII text plus the native degree glyph (BDF advance3); room captions are sanitized to ASCII. All pixels in52x16. Layout should be original coherent shaded miniature weather-station art matching improved EventTrigger, not plain outlines. No arbitrary incoming name text overflow: sanitize to uppercase ASCII and fit/truncate in bounded area; unknown UTF8 bytes skip/replace safely. Module name identifies additional indoor Couch; optional module label in 3x5 microfont is acceptable.

Each page is map:
- kind: indoor/outdoor/extra/rain/wind (string)
- view: climate/air/range/rain/rain_day/wind/wind_dir/offline
- name: raw module name string (display must sanitize; matching never depends on name)
- id: stable API module ID string (fixtures synthetic only)
- values: map of numeric finite dashboard fields exactly API keys (Temperature,Humidity,CO2,Noise,Pressure,min_temp,max_temp,Rain,sum_rain_1,sum_rain_24,WindStrength,WindAngle,GustStrength,GustAngle,max_wind_str), no invented readings
- stamp: source time_utc seconds or nil; received: now_ms of actual reading receipt
- battery: battery_percent numeric0..100 or nil
- reachable: bool; show_name: bool, copied from show_names setting

Kind mapping NAMain=indoor, NAModule1=outdoor, NAModule4=extra, NAModule3=rain, NAModule2=wind. Iterate body.devices then each device.modules explicitly, regardless field order/name/whitespace. Apply the optional parent station-ID filter during traversal; only normalized module records are retained, with no logs of raw account data. Dedupe by module ID, at most12 modules and24 pages, reasonable malformed-type bounds. Five visibility toggles filter actual discovered modules; toggles cannot manufacture missing hardware or values. Optional station_id text filter, defaultblank all owned stations.

At most two pages per module, only if that page has available numeric values. Zero is valid. No module gets excluded solely because Temperature absent.
- indoor/extra: climate if T or H; air if CO2 or Noise or Pressure. Main has climate T/H, air CO2 top + alternating Pressure/Noise bottom if both present. If no CO2, Pressure/Noise use separate rows. Extra usually climate + CO2 air.
- outdoor: climate T/H; range only when show_minmax=true and min_temp or max_temp exists. Down/up arrows replace LO/HI labels, with native temperature units.
- rain: rain if Rain or sum_rain_1; rain_day if sum_rain_24, with a 24H period label on its second metric line. Label Rain as latest reported mm, not fabricated mm/h; 1H/24H totals labeled explicitly.
- wind: wind if WindStrength or GustStrength; wind_dir only when show_direction=true and WindAngle/GustAngle/max_wind_str exists. Wind defaults km/h, do not confuse with m/s. Direction uses the native degree symbol, e.g. 225°; do not invent bearing when missing.
- recognized module without valid readings may have one offline page; expired data hides numbers regardless retained values.

Rendering: black canvas, without tinted background panels or dividers. Colored module illustration uses left~18px and the full height by default; show_names defaults to false; enabling show_names=true adds a compact 3x5 room caption for multi-room use. Up to two readable metric lines remain on the right. A CO2-only air page centers value plus ppm on one line, with no CO2 prefix; configured thresholds still control its color. Climate shows 23.2°C and 56% without T/H prefixes; the degree glyph follows the official BDF metrics. Indoor and extra modules use a shaded house; rain uses an umbrella with drops behind its canopy; wind uses a three-blade turbine with continuous elapsed-time rotation. Motion responds to current positive wind (speed or gust), never historical daily maxima, and is illustrative rather than physical RPM. Compact versions preserve optional room captions. Ambient illustrations do not claim weather forecasts. Rain/wind animated according to actual nonzero values, zero can show dry/calm. Include subtle page position markers and amber stale marker. Honor settings.useCelsius (core can add values display conversion or page celsius bool; agree before changing interface). Prefer core adds page celsius bool (defaulttrue), graphics converts T/min/max only; data remains nativeC. No wind unit setting needed (km/h explicit). CO2 color thresholds page co2_low/co2_high from settings (800/1500 defaults), artwork honors. Optional battery/status glyph never creates additional page. Diagnostic screen always readable instead of blank.

## Core and settings

netatmo_core.be.inc header/imports then class NetatmoV2 : NetatmoArtwork; generated script header+artwork+core+return NetatmoV2(). Builder rejects duplicate markers. Core init config defaults explicit even on new install. Keys include indoor,outdoor,extra,rain,wind bool true; station_id text blank; seconds number6 min3 max12; show_names,show_direction,show_minmax bool false; every number10 min5 max60; stale_minutes45 min20 max240; max_age_minutes180 min60 max1440 clamp>=stale; clow800/chigh1500 normal validated; quiet false,qfrom23,qto8 optional preserve original quiet functionality.

Keep last good per-module snapshot on malformed/network failures. Successful partial response merges by ID: a missing module is not refreshed and becomes unreachable; a module with no valid readings retains old snapshot/timestamps and becomes stale. A new valid partial dashboard replaces its fieldset rather than mixing old fields with new source timestamp. Source epoch timestamp valid finite positive; future timestamp unreasonable (>5min ahead) treated unknown. All comparisons use bounded seconds (epoch_ms() /1000 on firmware); tests handle 32-bit ints singleprecision. Poll time uses wrap-safe now_ms elapsed. At most one in-flight request, watchdog45sec and retry60sec, reject late callback with request generation. oauth.get false or throw clears busy and retries bounded; no busy stuck with synchronous callback. HTTP401 shows sign-in/auth diagnostic, 429 backs off at least10min, othererrors retry60sec. No response bodies/credentials in logs. Finite capped response check. Frozen page list for a visible turn so poll changes cannot invalidate duration/index mid-frame; next visit uses updated discovered modules. Quiet should_show false in interval but background polling continues. When not quiet should_show alwaystrue to display useful diagnostics even signed-in zero data. Duration finite seconds*max(1,pagecount); on_show resets monotonic elapsed and freezes pages. No network from draw.
